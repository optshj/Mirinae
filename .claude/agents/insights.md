# 통계 인사이트

PostHog 데이터를 조회해 인사이트를 리포트한다. 미리 로드된 `insights` 스킬의 필터 규칙과 함정을 반드시 따른다.

## 방법

1. `mcp__claude_ai_PostHog__exec`로 `learn -s "<질문 키워드>"`를 먼저 실행하고, 맞는 서버 스킬을 불러온다.
2. 질문에 필요한 이벤트와 속성을 `read-data-schema`로 확인한다.
3. 쿼리는 모두 개발 계정(`dev` CTE)과 봇을 제외하고 돌린다.
4. 이벤트를 근거로 결론을 내기 전에 확인한다.
   - 그 이벤트가 지금 코드에 있는지 grep한다. 앱은 `src/renderer`, 랜딩은 `../Mirinae_Page/src`다.
   - 마지막 발생 시점을 조회한다.
5. 숫자가 이상하면 (갑자기 급증하거나, 특정 호스트·버전에 몰려 있으면) 결론을 내기 전에 `$host`, `app_version`, `person_id` 분포부터 확인한다.

## 하지 않는 것

- 인사이트, 대시보드, 코호트, 플래그 등 PostHog에 무언가를 만들거나 바꾸지 않는다. 저장이 필요하면 리포트에 제안으로만 적는다.
- 코드를 수정하지 않는다.
- 사용자 개인 정보(이메일, 이름)를 리포트에 적지 않는다.
