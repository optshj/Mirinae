# 미리내(Mirinae) 기능 정리

Electron 기반 데스크톱 배경화면형 캘린더 앱. Google Calendar와 연동되며, 바탕화면에 직접 붙어 위젯처럼 동작한다.
(https://mirinaecalendar.store)

## 1. 데스크톱 배경화면 모드

- **배경화면 부착**: 바탕화면 아이콘 뒤(바탕화면 자체)에 창을 고정 부착. 프레임 없는 투명 창으로 동작.
- **클릭 통과 처리**: 바탕화면(탐색기)이 포그라운드일 때는 클릭/키 입력이 데스크톱으로 그대로 전달되도록 자동 전환.
- **화면조절 모드**: "화면조절" 버튼으로 배경화면에서 일시적으로 분리해 자유롭게 드래그 이동/리사이즈 가능. "완료" 버튼으로 다시 배경화면에 부착.
- **위치 초기화**: 트레이 메뉴에서 창을 기본 크기(1200x800)와 위치, 투명도 100%로 리셋.
- **다중 모니터 지원**: 여러 모니터 환경에서도 올바른 위치에 부착.
- **시스템 트레이 메뉴**: 버전 표시, 열기, 로그인 시 자동 실행 토글, 위치 초기화, 앱 종료.
- **로그인 시 자동 실행**: OS 시작 시 자동 실행 옵션 지원.
- **투명도 조절**: 20%~100% 범위에서 5% 단위로 조절.
- **창 상태 유지**: 창 위치/크기/투명도는 재실행 후에도 유지됨.

## 2. 캘린더 보기

- **월별 보기** (기본): 6주 그리드, 일요일/토요일 색상 구분, 오늘 날짜 강조, 이번 달 외 날짜는 흐리게 표시.
- **주별 보기**: 요일 헤더 + 하루종일/여러 날 일정 스트립 + 시간대별(00:00~24:00) 그리드. 마우스 휠 및 버튼으로 스크롤.
- **보기 모드 전환**: 월별/주별 토글, 설정이 유지됨.
- **이전/다음 탐색**: 헤더의 화살표로 월/주 이동.
- **캘린더 접기/펼치기**: 캘린더 영역 전체를 접어서 숨길 수 있음.
- **하단(Footer) 접기**: 하단 일정 패널만 별도로 접기 가능.
- **일정 표시 줄 수 조절**: 하루에 표시할 일정 줄 수를 1~5개로 설정, 초과분은 "+N개 일정"으로 표시.
- **일자 상세 모달**: 날짜(또는 주별 보기의 시간 셀)를 더블클릭하면 해당 일의 일정 목록과 추가/수정 폼이 담긴 모달이 열림. D-Day 뱃지(오늘/D-n/D+n) 표시.

## 3. 일정 관리 (Google Calendar 연동)

- **양방향 동기화**: 사용자의 기본 Google Calendar를 실시간으로 읽고 씀 (약 10분 주기 자동 재조회).
- **일정 추가**: 제목, 날짜 범위, 시간 범위, 하루종일 여부, 반복, 색상을 지정해 추가.
- **일정 수정**: 모달 내 인라인 폼으로 즉시 수정.
- **일정 삭제**: 반복 일정은 "이 일정만 삭제" 또는 "모든 반복 일정 삭제" 중 선택 가능.
- **실행취소(Undo)**: 추가/수정/삭제/드래그 이동 시 5초 카운트다운이 있는 되돌리기 토스트 제공.
- **하루종일 일정**: 폼 내 토글 스위치, 단축키 `Ctrl+D`로도 전환 가능.
- **여러 날 일정**: 두 달치 달력이 함께 보이는 범위 선택 UI로 시작~종료일 지정.
- **시간 범위 슬라이더**: 시작/종료 시각을 슬라이더로 설정.
- **반복 일정**: 반복 안 함 / 매일 / 매주 / 매월 / 매년.
- **일정 색상**: Google Calendar 색상 팔레트에서 선택.
- **색상 필터**: 설정 메뉴에서 특정 색상만 골라 보이도록 필터링, 필터 초기화 가능.
- **드래그 앤 드롭 이동**: 일정을 다른 날짜로 드래그해 이동 (월별/주별 보기 모두 지원), `Esc`로 취소, 이동 후 되돌리기 가능.
- **공휴일 표시**: 한국 공휴일을 읽기 전용 항목으로 표시(추가/수정/삭제 불가), 설정에서 켜고 끌 수 있음.

## 4. 하단 패널 (Footer)

- **오늘의 일정**: 오늘 등록된 일정 목록.
- **다가오는 일정**: 내일 이후 예정된 일정 목록.
- **색상별 필터 일정**: 색상을 선택해 해당 색상의 다가오는 일정만 모아보기.
- 각 목록은 항목이 많을 경우 위/아래 페이징 지원.

## 5. 계정 / 인증

- **Google OAuth 로그인**: 시스템 브라우저를 통한 OAuth 2.0(PKCE) 로그인.
- **자동 로그인**: 앱 시작 시, 네트워크 재연결 시 토큰 자동 갱신 시도.
- **로그아웃**: 저장된 인증 정보 삭제.
- **로그인 유도**: 비로그인 상태에서 일정 추가 시도 시 로그인 안내 문구와 버튼 표시.

## 6. 개인화 설정 (헤더 설정 메뉴)

| 항목 | 설명 |
|---|---|
| 구글 로그인/로그아웃 | 계정 연결 관리 |
| 화면조절 | 창 이동/리사이즈 모드 시작·종료 |
| 문의하기 | 외부 문의/버그 제보 페이지 열기 |
| 투명도 | 20~100% 조절 |
| 일정표시 | 표시 줄 수 1~5 조절 |
| 다크모드 | 라이트/다크 테마 전환 (OS 설정 감지) |
| 공휴일 표시 | 한국 공휴일 표시 여부 |
| 하단 접기 | 하단 패널 접기 |
| 일정 필터링 | 색상별 필터 |
| 앱 종료 | 앱 종료 |

헤더 툴바에는 이 외에도 월별/주별 보기 전환, 캘린더 접기/펼치기, 새로고침 버튼이 별도로 있음.

## 7. 단축키

| 단축키 | 동작 |
|---|---|
| `Ctrl+Enter` | 일정 추가 폼 열기 / 현재 열린 폼 제출 |
| `Ctrl+D` | 일정 폼에서 하루종일 토글 |
| `Esc` | 진행 중인 드래그 이동 취소 |

## 8. 알림 / 인앱 메시지

- **토스트 알림**: 일정 추가/수정/삭제, 로그인 오류, 입력 검증 실패 등에 대한 성공/오류/경고 알림.
- **패치노트 팝업**: 업데이트 후 첫 실행 시 새 기능/개선/수정 내역을 카드로 안내.
- **업데이트 준비 알림**: 자동 업데이트가 다운로드 완료되면 "나중에" / "지금 설치" 선택 카드 표시.

## 9. 자동 업데이트

- 새 버전을 자동으로 다운로드하고, 사용자 확인 후 설치 및 재시작.

## 10. 데이터 저장

- **창 상태**: 위치, 크기, 투명도, 일정 표시 줄 수, 보기 모드 등은 로컬에 저장되어 재실행 시 복원.
- **인증 정보**: OS 자격 증명 저장소에 안전하게 보관.
- **환경설정**: 다크모드, 하단 접기, 색상 필터 등은 브라우저 로컬 저장소에 보관.
- **일정 데이터**: 로컬 DB 없이 항상 Google Calendar에서 실시간 조회 (오프라인 캐시 없음).
